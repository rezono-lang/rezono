# Can one service reach another?

For an ordered pair of service IDs return one row per derived function and port, sorted by function and port. Include the consumer demand, chosen provider or unique-provider justification, and matching offer as evidence. Report unknown endpoints first. For known endpoints without a flow, report no matching demand, missing offer, ambiguous provider or different selected provider as applicable. Findings about identity and recovery accompany matching rows. Reachability alone grants no authorization.

A boolean answer loses both alternative ports and the evidence needed to review a change.
