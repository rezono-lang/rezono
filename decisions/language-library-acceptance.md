# Acceptance of the library migration

Use two isolated packs with identical pack identity, channels, Dutch labels and messages. The existing library is the independent schema and data oracle. During migration, stage its candidate sources in `examples/library/candidate/`: schema module `library`, and dataset modules `valid` and `errors`. Each has an authored .rezono file and its compiler form; the normal reader must regenerate that form from the source before retiring the original. In each data module, one named dataset encloses its fact declarations. The module name and dataset name coincide. Include only the selected form's schema and facts in its build directory: the candidate build copies `candidate/` to its own `rezono/` and declares the three modules in its own pack.yaml.

The candidate does not stage in `examples/library/rezono/`. Every file there must be declared in pack.yaml (`rezono_module.declared` refuses an undeclared one), and declaring the modules would make the one pack hold its schema and facts twice while the legacy files stay. `candidate/` is no definition directory, so `pack.read`, the pack hash and the legacy tests that read `examples/library` ignore it. A pack contract that tolerates undeclared or staged modules was considered; it would loosen a refusal for every pack to serve one migration. When both live representations pass, the candidate moves to `rezono/`, is declared, and the legacy files leave the pack as std-access's did.

`valid` is a keyword, so its dataset is written in backticks, `` dataset `valid` ``, and its JSON holds the bare name `valid`, as a keyword is written wherever a declaration names it (decisions/language-metadata.md). The module file stays `valid.rezono`.

For data loading, allow `facts.load(model, form_path)` to consume a named dataset's module form. Resolve kind and slot names through the schema. Reuse the ordinary typed fact loader after decoding its records. The independently assignable Boolean/identifier case only requires the scalar table decoder in the facts component. Dataset discovery, lists, records, missing cells and reader syntax are separate dependencies. The entire conversion also needs kind identity, numeric and collection constraints, inline and inherited kinds, membership conditions, path equality, schema identity and layer metadata. Work on shared parser and schema lowering files in the order of the existing tasks. The schema contract must accept these declarations. A rule-block contract alone does not accomplish that.

Evaluate every typed row and every integrity finding for both datasets against the authored pack; the checked-in expected findings are a second oracle. For example, l2 follows copy 1002 and staff s2 to oost on both routes. In errors, l3 follows copy 1003 to centrum and s2 to oost. The ordered endpoints are the evidence for the path-equation violation. A member-branch requirement and the wrong subtype on l4 remain separate findings. Library contains integrity constraints and no derived Datalog rules; the separate relational-witness acceptance case covers packs with derivation rules.

Compare the full bundle after validating its local source references. Only declaration positions and the owning schema file are projections of provenance for this fixture. Preserve schema identity, stable identifiers, order, checks, sentences, labels, messages and channels. Check each dataset's authored location for the two sampled loans as well. Preserve the legacy files until both live representations pass. At that point freeze their reviewed semantic expectations before removing duplicates.

The compiler acceptance test consumes forms, so the Node suite independently regenerates and compares every submitted library form, including its spans, to its own source. Supplying the missing three authored modules is part of the full migration task. The schema-reader and schema-lowering cases precede it, as do the dataset decoder, named-dataset discovery and conditional requirement. The separate rule-block witness case has no execution dependency here because Library produces no derived Datalog relations.
