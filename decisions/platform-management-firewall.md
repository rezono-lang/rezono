# Compare a managed router table in both directions

Place the enforcement function on the router crossing the two zones. Select an implementation through sourced product data. The common loop renderer consumes the derived platform allowances. The desired identity of an allowance consists of its source interval, destination address, protocol and inclusive port interval. Kernel handles and enumeration order may change without changing an allowance.

A complete router sweep has an explicit run, router and managed table. Project only the records in that scope and compare the two sets. Report an unrequested observed allowance as extra and an absent intended allowance as missing. A partial sweep leaves the comparison unknown. Attach both the policy or desired row and the complete observed scope to each finding. The observed-first rule complements the desired-first comparison in the loop pack.

The disposable example has one unchanged allowance on TCP 443. Desired TCP 8443 and observed TCP 9443 demonstrate both directions. An identically shaped allowance in a different table or earlier run does not satisfy the requested port. In the live trial, use the shared router renderer for the applied bytes, then independently read the actual managed table after a controlled fixture change. Keep the scoped read and desired publication as evidence for both findings.
