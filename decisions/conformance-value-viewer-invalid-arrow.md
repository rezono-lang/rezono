## Deferral

The [view contract](../contracts/view.yaml) supplies the typed description of a view. The proposed observation is the rendered treatment of an invalid arrow. The current conformance corpus exercises data and proof semantics, while the map and flow rendering tests are tracked separately.

Revisit with a viewer fixture that renders the same reference in invalid and unknown states and checks the displayed distinction. The input state on its own does not establish the drawing.
